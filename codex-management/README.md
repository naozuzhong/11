# Codex 通用管理机制
这是一套可迁移的工作约定与空白模板。只包含机制，不包含任何人的记忆、项目资料、成果或已安装插件。

## 使用
1. 选择本机统一的管理根目录，通常是自己的 Codex 管理目录。文中的 `<管理根目录>`、`<项目名>` 和 `<申请接收聊天>` 都是待替换项。
2. 审阅 [全局规则](AGENTS.md)，将适用条款合并到本机规则；已有文件逐项合并，不整体覆盖。仓库里的模板不会自动改变本机设置。
3. 使用 [项目模板](projects/_template/README.md) 创建实际项目，再登记到 [项目索引](projects/INDEX.md)。模板本身不算实际项目。
4. 按 [定时维护说明](schedules/README.md) 在自己的应用中配置任务与申请接收聊天。保存这些提示词不会自动启用任务。
5. 在本机使用和积累真实内容。此公开模板仓库仅维护通用规则；不要将真实记忆、工作资料、输出或审核记录推送回来。

## 目录分工
|位置|用途|
|---|---|
|AGENTS.md|全局执行约定|
|memory/|经确认的跨项目长期记忆；本包只有空白索引|
|skills/|可重复方法的管理说明|
|plugins/|插件管理说明|
|projects/|项目索引和空白项目模板|
|rubbish/|全局归档与恢复清单模板|
|schedules/|四项定时任务的说明和提示词|

项目内：memory 保存项目长期背景和决策；references 保存进度与版本；work 保存输入参考资料；outputs 保存经确认归档的成果；rubbish 保存中间文件与可恢复归档。

默认时区 Asia/Shanghai，可由使用者调整。内置记忆功能是否启用由接收者在自己的应用中决定；本模板不携带账号配置或修改其设置。目录隐藏规则仅用于接收者本机管理根目录，不用于隐藏本仓库的说明文件。
