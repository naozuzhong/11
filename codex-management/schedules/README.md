# 定时维护设置
以下是可供接收者配置的任务提示词，不是已经安装或运行的自动化。接收者在自己的应用中创建任务，设置可访问的管理根目录、时区和申请接收聊天；不要复制别人的任务 ID、聊天 ID、历史审批或登录配置。

|任务|默认时间（Asia/Shanghai）|提示词|
|---|---|---|
|记忆维护|每日 22:00|[记忆维护](memory-review.md)|
|进度与版本审核|每日 22:30|[进度审核](progress-review.md)|
|成果审核|每日 23:00|[成果审核](output-review.md)|
|垃圾清理审核|每周日 21:30|[清理审核](rubbish-review.md)|

启用前将提示词中的占位项替换为接收者自己的设置，并选择同一个申请接收聊天。日常与定时检查共享这个聊天中可核实的审核状态。读取能力或权限不足时报告具体范围，不假定能够访问所有历史。
无变化不打扰；新候选、完成、失败或需要处理时报告。创建任务不代表批准保存或删除。GitHub 保存这些文件不会使任务自动运行，也不会自动连接本地文件。
